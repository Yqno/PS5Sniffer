# PS5Sniffer
IP Forward from Linux to PS5 with LAN Cable to Sniff Any Connections with Tools installed like Wireshark and use different filters

You have to be on Linux, having a WIFI Connection and a LAN Cable connected from the PC to the PS4/PS5 and run this script to give the Console an IP Address
